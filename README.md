# Context Ladder

一个中文交互式短文项目，用“上下文阶梯”解释 Agent 的渐进式披露（progressive disclosure）：不给模型一次性投喂所有资料，而是让它通过搜索、阅读和递归引用，自行发现完成当前任务所需的最小上下文。

![Context Ladder 页面头图](assets/context-ladder-hero.png)

## 内容

- 一个可点击的四层演示：从问题信号，到搜索入口、递归展开和执行收束。
- 一篇解释该设计思想的中文短文。
- 三个可迁移的创新场景：客服、临床协作、工业运维。
- 一份设计检查，帮助判断新能力应当成为新工具，还是应通过可发现的知识路径加入现有系统。

## 运行

这是一个无构建步骤的静态网站。直接打开 `index.html` 即可，或使用任意静态服务器：

```sh
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 核心观点

渐进式披露不是单纯的界面折叠，也不是减少信息量。对 Agent 而言，它意味着：

1. 先提供可靠的基础动作，例如搜索、读取、查询和执行。
2. 将专业知识写成可被发现和递归阅读的资料或 Skill。
3. 让每次上下文展开都由当前任务和前一层证据触发。
4. 在信息足以行动时停止，保留来源和决策路径。

这种设计能减少无关上下文、降低工具膨胀，并让系统更能适应变化。
